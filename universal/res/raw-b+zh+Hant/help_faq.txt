
<b>問: 金手指關不掉怎麼辦? 這是 bug 嗎?
答: 金手指會在遊戲執行時修改記憶體。即使你關掉金手指，多數的修改操作也是不可逆的，這和金手指的運作原理相違背。（金手指遵循 Action Replay 代碼規範）。最好的辦法是關掉金手指後儲存遊戲內存檔再重設遊戲，如此一來，只要金手指不影響存檔部分，它就會被完全關閉。用即時存檔是無效的，必須用遊戲內存檔。

<b>問: 為什麼我的即時存檔或遊戲內存檔總是被刪除?
答: DraStic 理論上不應該會這樣做。在我們目前看到的所有情況中，都是手機中安裝的其他應用導致的。因此，如果安裝了垃圾清理工具或防毒軟體，請確保已將模擬器儲存資料的資料夾加入到白名單中。

<b>問: 為什麼觸控螢幕出現在錯誤的螢幕上，或者影像在閃爍?
答: 在視頻設定中關閉「多執行緒 3D 渲染」和「強制上螢幕為主螢幕」，這些選項在某些遊戲中可能會導致此類問題。

<b>問: DraStic 將來會支援 3DS/2DS 遊戲嗎?
答: 永遠不可能。3DS 是另一世代掌機，就像 NGC 對於 N64 一樣。2DS 也不可能，因為除了螢幕外，它和 3DS 差不多。

<b>問: 玩寶可夢按 Start 鍵開不了選單。
答: 其實，遊戲中的 Start 鍵毫無用處（但可以改設定），你應該按 X 鍵來打開選單。

<b>問: 下一版本什麼時候發布?
答: 原作者已經下架應用，在作者承諾的原始碼開源之前，都不會有新版本。（反編譯二次開發版本除外）

<b>問: DraStic 有多快?
答: 很大程度上取決於你想要執行的遊戲。一台 1GHz Cortex-A8 的裝置執行很多遊戲都需要大量的跳幀。而一台 1.4+GHz 雙核 Cortex-A9 的裝置在大多數情況下，執行大部分遊戲都很少或沒有跳幀。

<b>問: 是不是多核心運行效果更好?
答: 是的。如果你有多核心裝置，DraStic 就可以把螢幕渲染交給另一個執行緒，從而達到提速的目的。如果你勾選了多執行緒渲染這個選項，你就能得到更多提速，但這個選項可能會造成影像錯誤或不穩定。

<b>問: DraStic 是使用 GPU 來渲染圖像的嗎? GPU 是不是越快越好?
答: GPU 只用來柔化圖像以及提供濾鏡，所以 GPU 好壞不會有太大差距。OpenGL ES 並不是用來渲染 NDS 畫面的。由於 NDS 圖像硬體的特點，這種方式會使模擬不完全或者降速。

<b>問: DraStic 支援自製遊戲嗎?
答: 目前很多自製遊戲不支援，因為 DraStic 還不完全支援 DLDI 檔案系統，很多自製遊戲都要用到這個。然而原作者已經下架應用，建議嘗試隔壁 melonDS 安卓版。

<b>問: DraStic 支援多人遊戲還有 WIFI 連線嗎?
答: 原作者已經下架應用，要使用 WIFI 功能建議改用隔壁 melonDS 安卓版。

<b>問: 原始碼在哪?
答: 作者承諾開放的原始碼目前仍然未公佈。

<b>問: 其他平台有 DraStic 嗎?
答: 目前還有潘多拉掌機版(http://www.openpandora.org)
你可以在這裡免費下載潘多拉版 DraStic: http://repo.openpandora.org/?page=detail&app=DraStic
