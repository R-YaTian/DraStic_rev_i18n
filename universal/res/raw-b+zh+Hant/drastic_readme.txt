<t1>1. 設定

點觸主選單中的「配置選項」，或遊戲選單中的「選項」進入設定

注意：
並非所有選項在所有裝置（例如 Android TV）上都可用。

選項如下：

<t2>1.1 視頻

<b>跳幀類型
設成「手動」或「自動」來進行跳幀。當某一幀被跳過時，不會有任何 2D 或 3D 圖形被渲染（雖然多邊形引擎仍然透過模擬在運作），這樣可以帶來提速。
關於跳幀的數值「N」：如果您設成手動，那麼每（N + 1）幀裡就會有 N 幀被跳過。例如，如果您把跳幀數設成 2，那麼只有 1/3 的幀數會被渲染。
如果跳幀類型是自動，那麼模擬器就會只在模擬速度低於正常值時跳幀，但跳幀數最大不超過 N。
請注意跳幀過多會明顯地使遊戲成為幻燈片甚至打亂遊戲，所以您的遊戲在執行中卡成幻燈片的話，請嘗試關閉跳幀。

<b>跳幀值
用於上述自動或手動跳幀模式的跳幀值，範圍是 0 到 9

<b>安全跳幀
啟用以使用安全跳幀策略。

<b>快進最大速度
這是當您透過遊戲選單或者外接控制器按下快進鍵時，遊戲執行的最大速度
注意：實際快進速度還要取決於您的裝置的配置，如果您選了 300%，但是裝置只能加速到 200% 時，加速最大只會加到 200%

<b>顯示加速圖示
啟用/停用當快進啟用時的「>>」圖示

<b>濾鏡
選擇濾鏡，濾鏡透過 GPU 著色器實現，所以理論上對遊戲執行速度的影響很小

<b>高解析度 3D 渲染
3D 圖形將以正常解析度的兩倍進行渲染。
這可以提升畫質並帶來更流暢的動畫效果，但需要較高效能的硬體（最好是四核 CPU）才能以較好的速度執行。

<b>16 位渲染
啟用 16 位材質形式。畫面品質會下降，但是在某些裝置上會提速

<b>停用邊緣標記
停用邊緣標記的功能

<b>強制上螢幕為主螢幕
NDS 有兩個顯示引擎，一個顯示 2D+3D 內容，另一個僅顯示 2D 內容。通常情況下，遊戲可
讓引擎在上下螢幕間切換。勾選此選項會忽視這種切換，強制上螢幕顯示主引擎（2D+3D）
下螢幕顯示副引擎（僅 2D）。這在某些遊戲中會有用，比如《索尼克》（衝刺、編年史）

<b>多執行緒 3D 渲染
如果您有多核裝置的話，DraStic 就可以把螢幕渲染交給另一個執行緒，從而達到提速的目的。
如果您勾選了多執行緒渲染，您就能得到更多提速，但這個選項會造成圖像錯誤和不穩定。
出現某些圖形問題時，請您先嘗試關掉這個選項。

<b>視頻輸出模式（Android 4.2.2 及以上）
設定 HDMI 視頻輸出。標準是「完全同步」，該模式下，視頻輸出裝置會顯示
與手機或平板電腦上完全一樣的畫面。
「按比例模式」和「全螢幕模式」僅顯示下方選項中選中的螢幕。

<b>輸出螢幕（Android 4.2.2 及以上）
選擇視頻輸出裝置顯示的螢幕

<b>視頻輸出邊框（Android 4.2.2 及以上）
修改視頻輸出時的邊框

聲音延遲為「低」時效果最好。但如果您的遊戲執行速度下降，請嘗試設定成「中」或「高」。

調整遊戲音頻的音量

<t2>1.3 虛擬按鍵設定（TV 模式中不可用）

<b>總是顯示 Start 鍵和 Select 鍵
當您在執行遊戲時，螢幕底部會有一個選單鍵，點擊它就會顯示一些功能按鍵。
Start 鍵和 Select 就在其中，但若勾選此項，Start 鍵和 Select 鍵將始終可見。

<b>選單鍵位置
設定選單鍵的位置
注意：如果您設定成「隱藏」，而且也沒有把它映射到實體按鍵上的話，您就無法打開快捷選單了。

<b>虛擬功能鍵 I、II、III
可以設定成以下功能：加速、快速存檔/讀檔、上下螢幕切換、螢幕佈局切換、顯示/隱藏虛擬按鍵、虛擬麥克風以及連發。
點擊連發即可切換連發模式，此時按住某個按鍵即可連發。連發只能用於 A、B、X、Y、L、R 鍵。

<b>皮膚
虛擬按鍵皮膚。「預設」即是模擬器自帶皮膚，應用資料目錄的 virtual_controller 資料夾下的「Simple」是 DIY 皮膚的樣本，可用於參考。
自訂的 <皮膚包檔名>.zip 檔中必須含有檔名與樣本一致的 PNG 圖片，才會顯示在此選項中。

<b>按鍵操作同時觸發 DS 觸控
若開啟此項，觸摸虛擬按鍵區域也會被視為觸摸位於按鍵下方位置的 DS 觸控螢幕

<b>按鍵震動
若開啟此項，每次按虛擬按鍵時都會有震動回饋

<b>停用十字鍵斜向輸入
若開啟此項，虛擬按鍵十字鍵只可用上下左右四個方向
在某些無需斜向操作的遊戲中，這很有用

<b>十字鍵觸摸有效區調節（1.0-2.0）
設定十字鍵額外的觸摸有效區

<b>動作鍵觸摸有效區調節（1.0-2.0）
設定 A/B/X/Y 鍵額外的觸摸有效區

<b>虛擬按鍵不透明度
設定虛擬按鍵不透明度
設成「0%」虛擬按鍵完全透明，設成「100%」完全不透明

<t2>1.4 外接控制器

<b>選擇按鍵映射方案
您最多可以為您的外接手把（如藍牙手把）或裝置上的實體按鍵（Nvidia Shield、Xperia Play）設定 3 組不同的按鍵映射方案
在這裡選擇您想要更改的映射方案，然後點擊下面的按鈕進行編輯

<b>控制鍵映射 / 特殊鍵映射
按這個按鈕來打開按鍵映射對話框，然後您就能映射控制器上的十字鍵和其他按鍵了
您還可以映射一個螢幕切換快捷鍵，當您使用單螢幕佈局時，這個功能會十分給力

<b>重命名
在某些裝置上，手把的名稱並不會自動識別。如果映射方案列表中顯示為未知的名稱，或者想要給一只手把保存兩種映射方案，您可以在按下此按鍵後修改顯示的名稱

<b>停用已映射的虛擬按鍵
若開啟此項，所有被映射到實體按鍵的虛擬按鍵，都不會再顯示

<b>加速鍵切換模式
在切換模式中，任何已映射的加速鍵都可以開關加速。如果停用此選項，就會變成僅在按下加速鍵時加速

<b>啟用控制器扳機鍵
使用外接手把上的 L/R 扳機鍵

<b>控制器右搖桿模式
用您外接手把上的右搖桿（或者觸控板）來進行某些遊戲的觸控操作
對於 FPS 遊戲來說，這很有用。可以依次嘗試三種不同模式（FPS 模式、搖桿模式或是觸筆模式），看看哪種更適合您的遊戲
如果設為「觸筆模式」，則搖桿將直接移動觸筆指標，該指標可透過指定按鈕按下

<b>震動裝置
決定震動功能使用裝置內建馬達還是控制器的震動馬達。
若裝置未內建震動馬達，即使選取「內建」選項也不會有震動效果回饋。

<b>右搖桿死區
設定觸摸模式下右搖桿的死區範圍

<t2>1.5 常規

<b>顯示 FPS
遊戲執行速度指示器

<b>透明 FPS 顯示器

<b>橫向模式旋轉
自動：啟用橫向佈局與直向佈局之間的自動旋轉。
如果當前佈局是直向模式，裝置就不會自動旋轉，因為有些遊戲需要那樣玩
橫向：所有橫向佈局固定為橫向顯示
反向橫向：所有橫向佈局固定為反向橫向顯示

<b>自動保存
當您退出 DraStic 時，自動保存您的進度
這項功能不會佔用常規即時存檔位，只有再次啟動 DraStic 並點擊主選單的「繼續」時才會自動讀取這個存檔

<b>從快捷方式開啟時讀取最近的即時存檔
從快捷方式開啟遊戲時，自動讀取最近的即時存檔
<i>注意：在遊戲瀏覽器中長按遊戲即可建立快捷方式

<b>覆蓋即時存檔需要確認
開啟此選項，每次覆蓋即時存檔時都會有提示
以防止您操作失誤，意外覆蓋存檔

<b>讀取即時存檔需要確認
每次讀取即時存檔時都會有提示

<b>啟用金手指
開啟全域金手指功能
如果您開啟的金手指有問題，導致無法進入遊戲時，請您關閉這個選項
這種情況下，暫時關閉金手指功能，並在進入遊戲後停用導致問題的金手指代碼
然後您就可以再次開啟金手指功能

<b>啟用 Lua
該選項可全域啟用 Lua 腳本處理。
有關 Lua 腳本的更多資訊，請參見第 8 章 Lua 介面。

<b>停用返回鍵
停用您裝置上的返回鍵響應。推薦您開啟這個選項，以防操作失誤
若停用此選項，則返回鍵可用於呼出模擬器選單

<b>停用選單鍵
停用您裝置上的「選單鍵」響應。

<b>預設佈局
設定全域預設佈局，當執行新遊戲時，則不再需要重新設定。

<b>連發速度
設定連發的速度/頻率

<b>資料儲存目錄
決定 DraStic 資料儲存目錄的位置。資料儲存目錄用於存放即時存檔、電池存檔、金手指資料庫等資料。
您可以在此自訂選擇指定的儲存路徑，重啟模擬器後完成資料遷移。
Android 10 及以上版本預設使用應用內建資料儲存作為資料儲存目錄，不支援直接使用內部儲存的 DraStic 資料夾。
Android 5–9 預設使用內部儲存的 DraStic 資料夾，但前提是已授予儲存權限。不支援使用應用內建資料儲存。
Android 4.4.x 無法修改資料儲存目錄，預設且只能使用內部儲存的 DraStic 資料夾。
Android 4.0–4.3 預設使用內部儲存的 DraStic 資料夾，不支援使用應用內建資料儲存，但允許自訂儲存路徑。

<t2>1.6 系統設定

在此您可以像真正的 NDS 韌體中一樣修改您的個人資料
這些資料比如您的暱稱，將被用在某些遊戲中

<b>Slot2 卡帶類型
配置 Slot2 卡槽模擬插入的卡帶類型

<b>強制系統時間作為實時時鐘
強制使用 Android 系統時間作為遊戲的實時時鐘（RTC）

<b>自訂系統日期與時間
我們改變了實時時鐘的工作方式，現在僅在模擬的 DS 啟動時才使用 Android 系統時間，之後時間將與模擬時間同步。
當您在遊戲中「快進」時，時間會顯得流動得更快；當您「減速」時，時間會變慢。
載入即時存檔時，時間會從保存時的狀態繼續，而不是當前的真實時間。
若要與現實時間重新同步，請重設遊戲並載入遊戲內存檔。
透過此設定，您可以指定實時時鐘的起始時間，而不是使用系統時間。

<t2>1.7 進階

<b>使用原始 .sav 存檔格式（無檔案註腳）
開啟該選項將會使得模擬器核心在處理遊戲內電池存檔時不再附加尾部資訊。
這樣電池存檔的檔案大小將會和卡帶的儲存晶片容量一致，
方便您將模擬器保存的電池存檔移動到其他位置使用。（例如 melonDS 模擬器、實體機燒錄卡等）

<b>在即時存檔中保存電池存檔
在即時存檔檔案中保存遊戲內存檔。這是為了確保遊戲內存檔和即時存檔同步
若二者不同步，在某些遊戲中（尤其是寶可夢）可能會造成掉檔

<b>啟用解壓功能
啟用此項，壓縮的遊戲會自動解壓並快取在您的內部儲存中。這樣會延長載入時間，但可以節省記憶體。

<b>啟用預載未壓縮的遊戲到記憶體
若啟用此項，則未壓縮的 .nds 遊戲檔將會被預載到記憶體中。
這會增加記憶體占用，但在一定程度上可提升遊戲效能。

<b>忽略遊戲卡帶限制
如果某些改版遊戲 ROM（如漢化版遊戲）讀取出錯，請開啟此項。

<b>自動裁剪 ROM
僅使用 ROM 檔案頭資訊中指定長度的資料。
這可以讓一些原本在裝置上存在問題的大型遊戲順利執行。

<b>使用低解析度 UI
這個選項會在低端裝置上自動勾選。在低端裝置上使用高占用的 UI 資源會導致不穩定。

<b>在渲染執行緒中休眠
在某些裝置上（尤其是執行 Android 5 及以上系統的 Adreno GPU），開啟此選項可能會帶來更好的效能。
您可以分別開啟或關閉此選項進行測試，看哪種方式能讓 DraStic 執行得更流暢。

<b>佈局編輯器自動校準
啟用後，在螢幕佈局編輯器中，螢幕會自動根據另一塊螢幕的位置和大小進行調整。
而在虛擬按鍵編輯器中，控制項元素會自動吸附到格線上。

<b>幀率穩定器（額外 CPU 負載）
當該值非零時，DraStic 會額外增加 CPU 負載，以嘗試強制讓裝置保持在高效能狀態。
這可能會在某些效能本應該足以全速執行遊戲且無需跳幀的裝置上，加快遊戲執行速度，但會以耗電量增加為代價。
在受影響的裝置上，可以嘗試逐步增加該值，直到目標遊戲能夠以全速執行。

<b>除錯資訊
僅顯示一些內部除錯資訊，一般情況下您無需關心此處。


<t1>2. 快捷選單

在遊戲中，您可以透過點觸螢幕底部的選單鍵打開此選單，或者按下映射功能為「打開選單」的實體按鍵。
該選單可以點觸操作，也支援用外接手把操作。

當您使用外接手把時，使用左搖桿或方向鍵進行選擇，使用映射為 B 鍵的按鍵確認。映射為 A 鍵的按鍵用於取消。
例如，如果您想透過快捷選單讀取快速存檔，按下十字鍵左鍵，然後按 B 鍵。
如果您想加速，則只需在打開該選單之後按下 B 鍵

快捷選單輪盤周圍的四個小圓形按鍵直接映射到以下按鍵：
L 扳機鍵：聲音開/關
R 扳機鍵：虛擬麥克風輸入（模擬吹氣聲）
Y 鍵：DS Start 鍵
X 鍵：DS Select 鍵

快捷選單有以下功能（從頂部開始順時針）：
- 合上 DS 螢幕
- 啟用/停用觸控操作
- 快速存檔
- 切換上下螢幕
- 打開完整遊戲選單
- 切換螢幕佈局
- 快速讀檔
- 啟用/停用虛擬按鍵

中央快進鍵「>>」用於啟用/停用加速

<t1>4. 螢幕佈局以及虛擬按鍵佈局自訂

在佈局編輯器對話框中，您會看到兩塊螢幕的當前位置。
點擊以選擇其中一個，然後您就可以將其移動到任意位置。

<t2>選單面板（底部）

<b>選單
點擊此處可將修改後的佈局保存為全局佈局（適用於所有遊戲）或僅保存為當前正在執行遊戲的佈局。
如果當前遊戲已有保存的自訂螢幕佈局，也可以透過點擊「刪除遊戲專用佈局」將其刪除。刪除後，該遊戲將再次使用全局佈局。
您可以用同樣的方式編輯虛擬按鍵佈局，方法是點擊「編輯虛擬按鍵佈局」。
「設定背景圖片」允許你為佈局設定或移除背景圖片。
背景圖片會在兩塊螢幕和虛擬按鍵的後方全螢幕顯示。
新增背景圖片可能會對效能產生一些影響！
支援的背景圖片格式為 .png、.jpg、.bmp；若不希望圖片顯示在裝置相簿中，也可以將這些檔案重新命名為 .dbg
圖片檔案必須放在資料儲存目錄的 backgrounds 資料夾下，才能在該選單中使用。

<b>重設回預設
在編輯器中將當前螢幕佈局重設為所選佈局的預設設定。
只有在重設後透過「選單」保存，預設佈局才會生效。

<b>編輯全局佈局 / 編輯當前佈局
如果同時保存了遊戲專用佈局和全局佈局，您可以在這裡選擇要編輯哪一個。
當前正在編輯的佈局會顯示在左上角。

<b>打開工具箱
點擊此處打開一組工具，幫助你自訂螢幕佈局。
橫向模式下工具排列如下（左到右、上到下）：
- 調整螢幕尺寸為裝置螢幕高度的 50%
- 將螢幕移到最上方
- 調整螢幕尺寸為裝置螢幕寬度的 50%
- 將螢幕垂直方向拉伸至最大
- 將螢幕移到最左邊
- 將螢幕放在裝置螢幕中央
- 將螢幕移到最右邊
- 將螢幕水平方向拉伸至最大
- 將螢幕尺寸設為 NDS 實機尺寸
- 將螢幕移到最下方
- 以原始直向佈局排列螢幕，並保持適當間距

在右側，您會看到整倍縮放按鈕 1x-8x（具體範圍取決於您裝置所支援的最大縮放倍數）。

<b>調整螢幕大小
點擊即可顯示縮放按鈕，使用縮放按鈕即可自由調整所選螢幕的大小。
關閉「保持比例」後，可以脫離長寬比限制來縮放螢幕。
通常雙擊螢幕會在最大和最小尺寸之間切換。
如果您為當前佈局選擇了背景圖片，並且該圖片上有顏色遮罩的區域用於放置螢幕，
您可以在該遮罩區域雙擊以自動把螢幕適配進去。

<b>注意：
要把螢幕移動到上方/中間、置中/靠左等位置，先按下工具箱中的「置中」按鈕，再選擇所需方向。

「原始佈局（帶間距）」按鈕在橫向和直向佈局下會有不同表現：
橫向佈局：會盡可能放大兩個螢幕，同時保持一定比例的間距。
直向佈局：會將兩個螢幕在當前大小下水平與垂直置中，並根據當前大小調整間隔。
因此，如果您裝置螢幕足夠大，並且想要獲得最接近實體機的螢幕佈局，
請先依次選擇每個螢幕，點擊「原始大小」按鈕，然後再點擊「原始佈局（帶間距）」按鈕。


<t1>5. 使用者設定檔

您可以在應用初始選單的右上角找到使用者選擇按鈕。
每位使用者都有自己獨立的資料目錄，用於保存即時存檔和電池存檔。選中的金手指以及其他所有設定也都是單獨使用者專屬的。
此外，本 Rev 版本還允許您刪除使用者，這功能在原始版本的 DraStic 中是沒有的，
但刪除使用者意味著該使用者保存的即時存檔、電池存檔以及其他所有資料都將被移除，此操作無法復原，請謹慎操作！


<t1>6. Slot2 卡帶

Slot2 卡帶模擬功能允許在虛擬的 Slot2 卡槽中插入一張虛擬卡帶，該卡槽在實體機上是存在的。
通常，該卡槽會被用來載入 GBA 遊戲，以啟用一些額外功能，或者在某些遊戲中進行存檔檔案傳輸（聯動）。

Slot 2 卡帶檔案應放置在資料儲存目錄的 slot2 資料夾下。
如果找到名為 <ROM 檔名>.gba 的檔案，那麼在載入 <ROM 檔名>.nds（或 .zip、.rar、.7z）時，它將被同時載入。
如果找到名為 <ROM 檔名>.sav 的存檔檔案，它將會被載入到卡帶記憶儲存區中。
存檔檔案應為無任何檔頭資訊的原始格式，並且應當能與 VBA 或 gpSP 生成的 .sav 檔案相容。支援的存檔晶片類型包括 SRAM、FRAM 和 Flash。

如果沒有找到 <ROM 檔名>.gba，則會預設載入 slot2_gamepak.gba（若存在）以及對應的 slot2_gamepak.sav


<t1>7. DLDI

如果載入了自製程式/遊戲，DraStic 會模擬成 R4 燒錄卡，並將模擬的 SD 卡讀寫操作重定向到名為 drastic_dldi.img 的檔案中。
該檔案應放置在資料儲存路徑的根目錄下。

您可以在 Linux 裝置上按如下操作以建立該映像檔：
dd if=/dev/zero of=drastic_dldi.img bs=1M count=<容量|單位MB> of=drastic_dldi.img
mkdosfs drastic_dldi.img

接著掛載該映像：

mkdir <掛載目錄>
sudo mount -t vfat drastic_dldi.img -o loop <掛載目錄>

掛載後，您就可以直接複製檔案到掛載目錄中去。最後透過以下命令卸載：

sudo umount <掛載目錄>

目前模擬器尚不會自動套用 DLDI 補丁，因此您必須確保該自製程式本身已支援 R4。
您可以直接使用已支援 R4 的自製程式，或者使用離線補丁工具來打補丁。
例如，您可以使用 dlditool，它目前可於此下載：

https://www.chishm.com/DLDI/index.html

下載 dlditool 以及 "R4(DS) - Revolution for DS: DLDI v1"，然後使用以下命令為一個符合 DLDI 標準的自製程式打上 R4 補丁：

dlditool r4tf.dldi <自製程式檔案名.nds>


<t1>8. Lua 介面

Lua 腳本可以放在資料儲存目錄的 scripts 資料夾下，並會在以下情況載入：
- 當載入遊戲時，若找到名為 <ROM 檔案名>.lua 的腳本。
- 若存在一個名為 "default.lua" 的腳本，則它會對所有遊戲生效並被載入。

<t2>8.1 Lua 回呼函式

在您的 Lua 腳本中可以定義以下 3 個回呼函式：

// 當載入新遊戲時會被呼叫
// 'game' 是一個字串，內容應為不帶副檔名的 ROM 檔名
// 您可以用該函式來開啟檔案，例如用於日誌記錄
<i>function on_load(game)
<i>end

// 當遊戲被卸載時呼叫（在載入新遊戲之前，或是 DraStic 退出時）
// 例如，您可以在此關閉先前開啟的檔案
<i>function on_unload()
<i>end

// 每一幀都會呼叫該回呼
// 您可以使用該回呼來修改按鍵狀態或記憶體
<i>function on_frame_update()
<i>end

<t2>8.2 Lua 常數

在腳本中可使用以下常數來取得／設定按鍵狀態：
- drastic.C.BUTTON_UP
- drastic.C.BUTTON_DOWN
- drastic.C.BUTTON_LEFT
- drastic.C.BUTTON_RIGHT
- drastic.C.BUTTON_A
- drastic.C.BUTTON_B
- drastic.C.BUTTON_X
- drastic.C.BUTTON_Y
- drastic.C.BUTTON_L
- drastic.C.BUTTON_R
- drastic.C.BUTTON_START
- drastic.C.BUTTON_SELECT
- drastic.C.BUTTON_FAST_FORWARD
- drastic.C.BUTTON_TOUCH

若您想測試某個按鍵是否被按下，可以這樣做：
<i>  if ((buttons & drastic.C.BUTTON_A) ~= 0) then
<i>    ...
<i>  end

若您想設定某個按鍵，可以這樣做：
<i>  buttons = buttons | drastic.C.BUTTON_A

<t2>8.3 模擬器核心相關 Lua 函式

<b>drastic.get_path()
返回一個字串，內容為資料儲存目錄的路徑

<b>drastic.get_buttons()
返回一個整數，表示目前的按鍵狀態
可使用 drastic.C.<constant> 中的常數來檢測單一按鍵的狀態

<b>drastic.set_buttons(buttons)
將 DraStic 的按鍵狀態設定為傳入的整數參數

<b>drastic.get_touch()
返回一個整數，觸控點的 X 座標存在高 16 位，觸控點的 Y 座標存在低 16 位

<b>drastic.set_touch(touch_x, touch_y)
將 DraStic 的觸控座標設定為傳入的參數值
這只會設定座標，若您想真正按下或放開觸控螢幕，
需要透過 drastic.set_buttons() 函式設定或清除 drastic.C.BUTTON_TOUCH

<b>記憶體存取函式
您可以使用以下形式的函式來取得／設定模擬 DS 的記憶體：
drastic.get_ds_memory_<cpu>_<size>(address)
drastic.set_ds_memory_<cpu>_<size>(address, value)

以下是所有可能的組合：
- drastic.get_ds_memory_arm9_8(address)
- drastic.get_ds_memory_arm9_16(address)
- drastic.get_ds_memory_arm9_32(address)
- drastic.get_ds_memory_arm7_8(address)
- drastic.get_ds_memory_arm7_16(address)
- drastic.get_ds_memory_arm7_32(address)
- drastic.set_ds_memory_arm9_8(address, value)
- drastic.set_ds_memory_arm9_16(address, value)
- drastic.set_ds_memory_arm9_32(address, value)
- drastic.set_ds_memory_arm7_8(address, value)
- drastic.set_ds_memory_arm7_16(address, value)
- drastic.set_ds_memory_arm7_32(address, value)

<t2>8.4 Android 相關 Lua 函式

<b>android.get_axis_lx()
若使用外接手把，返回左搖桿 X 軸的浮點數值

<b>android.get_axis_ly()
若使用外接手把，返回左搖桿 Y 軸的浮點數值

<b>android.get_axis_rx()
若使用外接手把，返回右搖桿 X 軸的浮點數值

<b>android.get_axis_ry()
若使用外接手把，返回右搖桿 Y 軸的浮點數值。

<b>android.get_rotation()
返回一個整數，表示目前裝置的旋轉角度（單位：度）
逆時針旋轉範圍為 [0, -180]，順時針旋轉範圍為 [0, 180]

<b>android.set_layout(layout)
設定目前的螢幕佈局（範圍 [0, 4]，順序對應選單中顯示的佈局順序）

<b>android.show_overlay(show)
顯示 (1) 或隱藏 (0) 虛擬按鍵覆蓋層

<b>android.set_screen_swap(swap)
啟用 (1) 或停用 (0) 螢幕切換功能
